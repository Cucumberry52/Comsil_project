실행 방법

1. ZIP 파일을 모두 압축 해제합니다.
2. Start.bat를 실행하거나 comsil_project.exe를 실행합니다.
3. 콘솔에 N M: 이 나오면 10 10처럼 가로 세로 크기를 입력하고 Enter를 누릅니다. 최소 5 5를 권장합니다.
4. Maze Example 창에서 File > Open으로 같은 폴더에 생성된 maze0.maz를 엽니다.
5. 방향키로 이동합니다. l: 밝게, b: 어둡게, f: 전체 화면. 메뉴에서 BFS/DFS를 선택할 수 있습니다.

Windows 10/11 x64용 Release 빌드입니다. DLL과 data 폴더를 실행 파일과 함께 유지하세요.
게임의 미로 크기 입력과 파일 열기 방식은 원래 프로그램과 같습니다.
원본 소스는 수정하지 않았으며, 작업 복사본에서 전역변수 중복 정의와 파일 열기 취소 시 반환값을 정리했습니다.
